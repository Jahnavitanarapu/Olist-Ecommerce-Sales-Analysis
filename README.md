# Olist E-Commerce Sales Analysis

An end-to-end E-Commerce Sales Analysis project using SQL, MySQL, and Microsoft Power BI to explore sales performance, customer behaviour, payment methods, product categories, and customer reviews.

## Project Overview

This project analyzes the Olist Brazilian E-Commerce dataset to identify business trends and generate meaningful insights through SQL queries and an interactive Power BI dashboard.

## Tools & Technologies

- SQL
- MySQL Workbench
- Microsoft Power BI
- Microsoft Excel (only if used in the project workflow)

## Project Structure

- `Raw_Data/` – Original dataset files
- `Cleaned_Data/` – Cleaned and prepared datasets
- `SQL_Files/` – SQL queries used for data analysis
- `PowerBI_Dashboard/` – Power BI dashboard file

## Key Performance Indicators (KPIs)

- Total Orders: 99.441K
- Total Customers: 96.096K
- Total Sales: 13.59M
- Average Review Score: 4.00

## Dashboard Features

- Monthly Orders Trend
- Top 10 Orders by State
- Payment Method Distribution
- Customer Review Score Analysis
- Top 6 Sales by Product Category
- Interactive Year and Month Filters
- Key Business Insights

## Key Insights

- Identified monthly order trends over the analyzed period.
- São Paulo (SP) recorded the highest number of orders among the states shown.
- Credit card was the most commonly used payment method.
- The average customer review score was 4.00 out of 5.
- Watches and Gifts was the highest-selling category in the dashboard.

## Project Objective

To demonstrate practical skills in data analysis, SQL querying, data cleaning, dashboard development, and business insight generation.
